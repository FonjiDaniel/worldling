# Worldling: Step 3 color kit

Open `01-guide/Worldling-Color-Guide.pdf` for the designed guide, or `01-guide/Worldling-Color-System.md` for the complete reference tables and rules.

Included:
- Final palette with exact HEX/RGB and rounded HSL.
- Three accent scales, 50 through 950, with original colors held at 500.
- Four semantic colors and their opaque dark message backgrounds.
- WCAG 2.2 AA/AAA contrast results for text and UI boundaries.
- A full 132-pair accent-scale contrast matrix.
- Usage ratios and tested button/link color guidance.
- Color-only CSS custom properties and JSON.
- Visual palette and contrast previews.
- A reproducible Python contrast audit.

The Step 2 logo files remain the approved logo source. This package covers Step 3 only. Fonts, component details, motion and the complete Tailwind theme follow in their later stages.

Use HEX as the color source of truth. Preview and PDF colors can vary with display settings and PDF viewers. The contrast results apply to the listed opaque sRGB pairs, not to an entire application's WCAG conformance.
