# Worldling: Step 5 visual language kit

Start with 01-guide/Worldling-Visual-Language-Guide.pdf. The Markdown version contains the complete editable specification.

Includes a six-world concept-art moodboard, 3D art direction, glass and control specifications, eight reusable SVG icons with optical small versions, illustration and background do/avoid examples, motion timings and easing curves, CSS recipes and JSON data.

The planet image is concept art. No production 3D meshes are included. The PNG and SVG boards illustrate the system; they are not the full Step 6 application mockups. The CSS recipes need to be integrated with the Step 3 colors and Step 4 typography.

See 06-source for verification scope. Rendered reference sheets are visually reviewed; the final app still needs testing with real content, browser zoom, keyboard navigation and reduced-motion settings.
