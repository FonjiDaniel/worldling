# Worldling: Step 7

This kit defines the brand voice and supplies English and French copy for the product.

- `Worldling-Voice-and-Tone-Guide.pdf`: eight-page visual guide.
- `Worldling-Voice-and-Tone.md`: complete editable writing guide, including tone and usage rules.
- `worldling-copy.en.json`: English message strings and tagline options.
- `worldling-copy.fr.json`: corresponding French adaptations.
- `worldling-copy-context.json`: usage conditions and original wording for each rewrite.

The guide contains five voice principles, the preferred vocabulary, three error messages, three empty states, three celebrations, three push or email subjects, and ten alternative taglines. The existing primary tagline remains the default. French uses a consistent, friendly tu.

The copy files have matching keys. The alternative taglines remain options for review. Only display event messages when the corresponding state has been confirmed by the product. Review localized strings in their actual interface, allowing French labels to wrap or gain space.

Step 7 ends here. Design tokens and the one-page brand summary belong to Step 8.
