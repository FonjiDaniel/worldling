## Refinements

The orbit rises 19 degrees to the right. Its master stroke is 22 units. The 12-unit gap is a transparent knockout on both sides of the front arc. The right leaf has about 15% more area and a higher tip. The planet remains a perfect solid circle before the ring knockout.

The approved imagegen refinement guided the direction. Production assets were rebuilt from simple vector geometry to make sizes, colors, gaps and outlines exact. Use the vector files as the source of truth.

## Small sizes

Use the standard master from 48px upward. At 32px and 16px use the supplied optical variants. These have a stronger ring and larger gap, a small sprout enlargement, and a tighter crop. All preserve the 19 degree ring and the original paths. The leaf asymmetry is intentionally subtle and is mainly visible above favicon sizes.

## Formats and color

SVG files are scalable vector assets. PNG files use sRGB color and true alpha where named transparent. The SVG gap is transparent, not a background-colored patch. Text is outlined, so there are no missing-font dependencies. The primary mark remains single color. The gradient mark is for hero use only.

This is the Step 2 logo system. The full color system, typography scale, visuals, applications, voice and developer design tokens belong to later steps and are not presented as finished here.
