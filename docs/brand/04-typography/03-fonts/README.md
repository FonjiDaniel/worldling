# Font files

Original variable TTF files and their license notices are included. WOFF2 files are format conversions of those originals with no glyph, axis or naming changes. The CSS uses font-display: swap.

Bricolage Grotesque source: https://github.com/ateliertriay/bricolage
Geist source: https://vercel.com/font
The original binary files were obtained from the Google Fonts repository in the preceding brand-kit stage.

Keep the OFL notices when redistributing fonts. The private static instances used to typeset the PDF are not included in this package.
